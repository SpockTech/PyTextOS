# PyTextOS™ 1.0

PyTextOS™ is a text-based operating system that can run on both modern and legacy systems. It has a text editor, a disk management utility, a help menu, and more. You can download it [here](https://github.com/SpockTech/PyTextOS/releases/tag/release).

## Installation instructions
Follow these steps to install PyTextOS™ to your computer.
1. Download the ISO
2. Create a bootable USB or CD/DVD
3. Insert the USB or CD/DVD into the computer
4. Power on the computer

Once you will see `Loading installer...`, wait for it to finish. Then, you will have to select a drive where you want to install the operating system.
